# Крестики-нолики (Tic-Tac-Toe) 🎮

Мини-игра «Крестики-нолики», разработанная на **C# WinForms**. 
Проект создан для фестиваля "Наука 0+ 2026", чтобы показать школьникам и студентам основы работы с графическим интерфейсом, 
обработкой событий и игровой логикой.

## 🚀 Как запустить игру

### Вариант 1: Скачать готовый файл (самый простой)
1. Перейди в раздел [Releases](../../releases).
2. Скачай последний файл `Tic-tac-toe.exe`.
3. Запусти его двойным кликом. 
> *Если Windows выдаст предупреждение (SmartScreen), нажми «Подробнее» -> «Выполнить в любом случае».*

### Вариант 2: Открыть исходный код в Visual Studio
1. Скачай проект (нажми зеленую кнопку `Code` -> `Download ZIP`).
2. Распакуй архив.
3. Открой файл `Tic-tac-toe.sln` в **Microsoft Visual C# 2010 Express** (или более новой версии).
4. Нажми `F5` (или кнопку «Пуск»), чтобы запустить игру.

## 🕹️ Управление
* Играют два игрока на одном компьютере.
* Игрок 1 (Крестики) ходит первым.
* Кликните левой кнопкой мыши по любой пустой клетке, чтобы поставить свой знак.
* Побеждает тот, кто первым соберет **3 знака в ряд** (по горизонтали, вертикали или диагонали).
* Сессия продолжается до **3 побед** одного из игроков. Ничья очков не приносит.

## 🛠️ Технологии
* **Язык:** C# (.NET Framework 4.0)
* **Среда разработки:** Microsoft Visual C# 2010 Express
* **Библиотеки:** System.Windows.Forms, System.Drawing

## 📂 Структура проекта
* `Form1.cs` — Основная логика игры (обработка кликов, проверка победы, сессия).
* `Form1.Designer.cs` — Визуальная часть (сетка 3x3, кнопки, фон).
* `Properties/Resources.resx` — Графические ресурсы (картинки крестиков, ноликов, фон стола).
